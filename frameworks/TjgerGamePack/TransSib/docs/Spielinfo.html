    • 1.1. Ziel des Spiels

     Für jede im Spiel verwendete Stadtfarbe erhalten die Spieler je eine Stadt zugeteilt. Ziel des Spieles ist es, alle eigenen Städte zu verbinden. Damit ist eine Runde beendet. Jene Spieler, die nicht alle ihre Städte erreicht haben, rücken die Anzahl der fehlenden Schienen auf der Punkteleiste nach vorn. Das Ende des Spiels hängt dann von den eingestellten Regeln ab.

    Jene Städte, die einen weiß-schwarzen Rand haben, kommen nur dann zum Einsatz, wenn mindestens die vorgegebene Anzahl an Spielern mitspielt. Durch Aktivieren der Option "alle Städte verwenden" werden diese Städte aber auch bei weniger Spielern mit einbezogen.

    1.2. Spielablauf

     Im ersten Spielzug setzt jeder Spieler seine Spielfigur auf einen beliebigen unbesetzten Kreuzungspunkt. Dies darf auch eine Stadt sein. Die Spielfigur ist dann der Ausgangspunkt für das eigene Schienennetz.

    Sobald die Spielfiguren gesetzt sind, werden die Schienen gebaut. Schienen können nur auf unbesetzten Linien gebaut werden. Auf einer einfachen Linie kostet dies eine Schiene, auf einer doppelten zwei Schienen. Die Mindest- und Maximalanzahl an Schienen, die pro Spielzug gelegt werden dürfen, kann eingestellt werden. Standardmäßig gilt: mindestens eine Schiene und maximal zwei Schienen.

    Jeder Spieler legt nur an das Schienennetz an, in dem seine Spielfigur steht. Das heißt die gelegte Schiene muss an die eigene Spielfigur angrenzen oder über Schienen mit ihr verbunden sein.

    Anmerkungen:
    • Spieler dürfen ihre Schienennetze miteinander verbinden und ab dann so wie ihr eigenes Netz verwenden.
    • Man darf an jeder Stelle vom eigenen Schienennetz abweichen.
    • Baut ein Spieler in einem Spielzug mehr als eine Schiene, so darf er sie auch an unterschiedliche Stellen des eigenen Netzes anlegen.

    1.3. Ende des Spiels

     Das Ende des Spiels hängt von den eingestellten Regeln ab.

    Ende nach Fehlerpunkten:
    Es kann eingestellt werden, nach wie vielen Fehlerpunkten das Spiel beendet wird. In diesem Fall ist das Spiel zu Ende, sobald der erste Spieler diese Anzahl überschritten hat. Standardmäßig ist die Zahl auf 12 Fehlerpunkte eingestellt.

    Zusätzlich kann auch die Barriere nach einer gewissen Anzahl von Runden versetzt werden. Sie wird dabei so versetzt, dass zwischen dem Spieler mit den meisten Fehlerpunkten und der Barriere nur noch zwei Punkte Abstand übrig bleiben. Überschreitet ein Spieler diese Barriere, so ist das Spiel zu Ende. Standardmäßig wird die Barriere nach der 2. Runde versetzt.

    Ende nach Runden:
    Das Spiel kann auch nach einer festgelegten Anzahl von Runden beendet werden; die Fehlerpunkte sind in diesem Fall nur für die Reihung der Spieler wichtig.

    • 2.1. Voraussetzungen

     TransSib und TransMap sind Java-Programme, sie benötigen daher eine Java-Laufzeitumgebung (getestet mit Version 1.3.1).

    2.2. Starten/Aufrufen

     Um TransSib bzw. TransMap zu starten, geben sie den Befehl

    java -jar TransSib.jar

    bzw.

    java -jar TransMap.jar

    in dem Verzeichnis ein, in dem sich die ".jar"-Dateien befinden. Sollte die Java-Laufzeitumgebung nicht im Pfad eingetragen sein, dann ist der Befehl "java" nicht bekannt. In diesem Fall muss man den vollständigen
    Pfad, also z.B.:

    C:\Programme\jdk1.3.1\bin\java -jar TransSib.jar

    eingeben.

    Falls Sie *.jar-Dateien registriert haben, reicht ein Doppelklick auf die entsprechende ".jar"-Datei aus. Hierbei ist aber zu beachten, dass das Arbeitsverzeichnis jenes Verzeichnis sein muss, in dem sich das Spiel befindet, da ansonsten nicht auf die Landkarten zugegriffen werden kann.
